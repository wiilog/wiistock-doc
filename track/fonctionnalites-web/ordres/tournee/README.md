# Tournée

**Chemin :** Ordre › Tournée

La page affiche les tournées sous forme de vignettes, rangées par date (de la plus récente à la plus ancienne), avec une carte à droite.

## Filtres

**Du / Au** (date de la tournée), **N° de tournée**, **Livreur**, **Statut** (En attente livreur, En cours, Terminée). Les filtres sont conservés d'une session à l'autre.

## Vignette de tournée

| Information                             | Détail                                                                                                                                                     |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Numéro**                              | **T** + année, mois, jour de la tournée + compteur (ex. : T261023-02).                                                                                     |
| **Livreur** et **Transports effectués** | Livreur affecté et nombre de transports traités / total.                                                                                                   |
| **Statut**                              | En attente livreur, En cours ou Terminée. Une tournée est terminée quand tous les points sont traités et qu'un emplacement de fin de tournée a été flashé. |
| **Créée le** / **Terminée le**          | Dates de création et de fin.                                                                                                                               |
| **Km estimés / réels**                  | Kilométrage prévu, puis réel une fois la tournée terminée.                                                                                                 |
| **Temps estimé / réel**                 | Durée prévue, puis réelle.                                                                                                                                 |

Une icône devant le numéro signale des UL écartées. Cliquez sur une vignette pour ouvrir le [détail de la tournée](details-dune-tournee.md).

## Carte

La carte montre la dernière position connue des livreurs en tournée : pratique pour ajouter une collecte près de l'endroit où ils se trouvent.

## Export

**Exporter au format CSV** exporte les données des tournées. Renseignez d'abord les dates **Du / Au**.
