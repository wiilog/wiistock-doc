# Types et champs libres

**Chemin :** Paramétrage › IoT › Types et champs libres

Sur les IoT, les **types sont figés** : ils correspondent aux catégories d'objets connectés (Température, Action, GPS, Température & Hygrométrie, Hygrométrie, Extender, Tracer, Zone, Gateway). Vous pouvez seulement leur ajouter des champs libres.

### 1. Créer les champs libres

Dans l'encadré **Champs libres**, cliquez sur **Modifier**, puis sur la ligne **+** :

| Colonne                       | Description                                                            |
| ----------------------------- | ---------------------------------------------------------------------- |
| **Libellé\***                 | Nom du champ (unique dans l'application).                              |
| **Typage\***                  | Texte, Nombre, Oui/Non, Date, Date et heure, Liste ou Liste multiple.  |
| **Éléments**                  | Valeurs de la liste, séparées par des « ; » (Liste et Liste multiple). |
| **Nb caractères (Min / Max)** | Longueur minimale et maximale autorisée.                               |
| **Valeur par défaut**         | Valeur pré-remplie à la création.                                      |

### 2. Les rattacher à un type

Cliquez sur un type, puis dans **Champs pour ce type**, ajoutez les champs libres avec **+** et cochez _Affiché / Obligatoire_ à la création et à la modification. Cliquez sur **Enregistrer**.

{% hint style="danger" %}
Supprimer un champ libre (poubelle en début de ligne) est irréversible.
{% endhint %}
