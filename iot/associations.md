# Associations

**Chemin :** IoT › Associations

La page liste les capteurs associés sous forme d'encarts : logo du type de capteur, nom du capteur et élément associé.

## Associer un capteur

{% stepper %}
{% step %}
### Choisir le capteur

Cliquez sur **Associer un capteur**, puis choisissez le capteur par son **Nom** ou son **Code**.
{% endstep %}

{% step %}
### Choisir l'élément

Choisissez le type d'**Élément\*** puis l'élément : **Emplacement**, **Unité logistique**, **Article** (code-barres) ou **Véhicule**. Indiquez si besoin une **Date de fin d'association**.
{% endstep %}

{% step %}
### Enregistrer

Cliquez sur **Enregistrer**.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Un capteur n'est associé qu'à un seul élément à la fois, et un élément ne peut pas être associé à deux capteurs.
{% endhint %}

## Filtrer

* **Type de capteur** : Température, Température & Hygrométrie, GPS, Hygrométrie, Tracer, Zone, Gateway ;
* **Élément associé** : Emplacement, Unité logistique, Article, Véhicule, Préparation, Ordre de collecte ;
* **Sélectionner un capteur** : recherche par nom.

Tous les filtres sont actifs par défaut.

## Codes couleur (température)

| Couleur du nom | Signification                     |
| -------------- | --------------------------------- |
| Rouge          | Température au-dessus de 25 °C.   |
| Noir           | Température entre 10 °C et 25 °C. |
| Bleu clair     | Température en dessous de 10 °C.  |
