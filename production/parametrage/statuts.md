# Statuts

**Chemin :** Paramétrage › Production › Paramétrage complet › Statuts

Chaque type de demande a ses propres statuts. Cliquez sur **Ajouter des statuts** (ou sur une ligne pour la modifier) :

| Colonne                                                           | Description                                                            |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Libellé\***                                                     | Nom du statut.                                                         |
| **État\***                                                        | À traiter, En cours, Partiel ou Traité (colonnes de la vue Modulaire). |
| **Type\***                                                        | Type de demande concerné.                                              |
| **Statut par défaut**                                             | Statut proposé à la création.                                          |
| **Envoi d'emails au demandeur**                                   | Email au demandeur au passage à ce statut.                             |
| **Affichage sur planning**                                        | La demande apparaît sur le planning.                                   |
| **Création d'un mouvement de dépose sur l'emplacement de dépose** | Mouvement de traçabilité automatique.                                  |
| **Proposition de générer une demande d'acheminement**             | Choisissez le type d'acheminement proposé au passage à ce statut.      |
| **Contact(s) à notifier**                                         | Utilisateurs prévenus par email.                                       |
| **PJ obligatoire**                                                | Une pièce jointe est exigée pour passer à ce statut.                   |
| **Couleur** / **Ordre\***                                         | Couleur du statut et position dans la liste.                           |
