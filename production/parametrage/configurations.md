# Configurations

**Chemin :** Paramétrage › Production › Paramétrage complet › Configurations

| Paramètre                                                                                         | Effet                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Si urgence détectée, envoi d'email de notification à chaque changement de statut aux contacts** | Utilisateurs prévenus à chaque changement de statut d'une demande urgente.                                                                                             |
| **Si urgence détectée, demandeur en copie de l'email de notification**                            | Le demandeur est mis en copie.                                                                                                                                         |
| **Filtres de la liste des demandes**                                                              | Champs fixes proposés comme filtres sur la page Liste des OF (ex. : Numéro d'OF, Urgence, Date attendue, Code produit/article, Emplacement de dépose, Pièces jointes). |

Cliquez sur **Enregistrer** pour valider.
