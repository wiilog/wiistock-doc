# Paramétrage

l existe 4 grandes parties aux paramétrages des demandes de production ou suivi de fabrication.

* Configuration : Pour gérer les emails si urgence détectée
* Types & champs libres : Pour catégoriser les demandes.
* Statuts : Pour gérer les affichages de statuts et leurs libellés.
* Champs fixes : Pour gérer l'affichage des champs fixes des demandes.

| Rubrique                                            | À quoi ça sert                                                     |
| --------------------------------------------------- | ------------------------------------------------------------------ |
| [Types & champs libres](types-and-champs-libres.md) | Types de demandes de production et leurs champs libres.            |
| [Champs fixes](champs-fixes.md)                     | Champs affichés et obligatoires sur les demandes.                  |
| [Statuts](statuts.md)                               | Workflow de chaque type, planning, acheminements et notifications. |
| [Configurations](configurations.md)                 | Emails d'urgence et filtres de la liste des OF.                    |
