# Mise à jour - Détrompeurs web, filtres sur type de production et tournées & IOT

## Détrompeurs WEB&#x20;

Vous avez maintenant la possibilité de créer des détrompeurs sur les mouvements de traçabilité WEB. L'utilisateur verra une pop-up s'afficher dès qu'un détrompeur s'activera sur l'UL scannée.&#x20;

<figure><img src="../../.gitbook/assets/image (187).png" alt=""><figcaption></figcaption></figure>



## Filtre des types de production&#x20;

Sur le paramétrage utilisateur, il est maintenant possible d'intégrer les types de demandes de productions visibles WEB pour cet utilisateur. Ainsi, il n'aura accès qu'aux types renseignés sur son profil.&#x20;

Comme toujours, si le filtre est vide, alors tous les types seront visibles à l'utilisateur.&#x20;

<figure><img src="../../.gitbook/assets/image (190).png" alt=""><figcaption></figcaption></figure>

## Filtre des types de tournées

Sur le paramétrage utilisateur, il est maintenant possible d'intégrer les types de demandes de tournées visibles WEB et NOMADE pour cet utilisateur. Ainsi, il n'aura accès qu'aux types renseignés sur son profil.&#x20;

Comme toujours, si le filtre est vide, alors tous les types seront visibles à l'utilisateur pour la partie WEB et aucune pour la partie NOMADE.&#x20;

<figure><img src="../../.gitbook/assets/image (188).png" alt=""><figcaption></figcaption></figure>
