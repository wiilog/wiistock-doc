# Mise à jour - Détrompeurs web, filtres sur type de production et tournées & IOT

## Détrompeurs WEB&#x20;

Vous avez maintenant la possibilité de créer des détrompeurs sur les mouvements de traçabilité WEB. L'utilisateur verra une pop-up s'afficher dès qu'un détrompeur s'activera sur l'UL scannée.&#x20;

<figure><img src="../../.gitbook/assets/image (187).png" alt=""><figcaption></figcaption></figure>



## Filtre des types de production&#x20;

Sur le paramétrage utilisateur, il est maintenant possible d'intégrer les types de demandes de productions visibles pour cet utilisateur. Ainsi, il n'aura accès qu'aux types renseignés sur son profil.&#x20;
