# Configurations

**Chemin :** Paramétrage › Stock › Configurations

### Références

| Paramètre                                                                                                   | À quoi ça sert                                                                                                                                                     |
| ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Emplacement par défaut pour les Références en gestion quantité par référence à la création en Brouillon** | Emplacement attribué automatiquement aux références créées en brouillon (pour les rôles autorisés à en créer).                                                     |
| **Valeurs du champ "Types de documents associés" d'une référence article**                                  | Liste des valeurs proposées dans le champ « Types de documents associés » d'une référence (ex. : pdf, txt, ppt). Saisissez une valeur puis validez pour l'ajouter. |
| **Image par défaut des références**                                                                         | Image affichée pour toutes les références qui n'ont pas d'image. Cliquez sur le crayon pour choisir une image, ou sur la flèche pour revenir à l'image d'origine.  |

Cliquez sur **Enregistrer** pour valider.
