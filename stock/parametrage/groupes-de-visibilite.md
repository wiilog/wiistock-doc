# Groupes de visibilité

**Chemin :** Paramétrage › Stock › Groupes de visibilité

Un groupe de visibilité limite les références qu'un utilisateur peut voir : il ne voit que les références de ses groupes.

{% hint style="info" %}
Un utilisateur **sans** groupe de visibilité voit **toutes** les références.
{% endhint %}

{% stepper %}
{% step %}
#### Créer les groupes

Cliquez sur **Ajouter** (ou sur une ligne pour la modifier), puis ajoutez autant de lignes que nécessaire avec **+** :

* **Libellé\*** : nom du groupe ;
* **Description\*** ;
* **Actif** : un groupe inactif n'est plus proposé dans les listes.

Cliquez sur **Enregistrer**.
{% endstep %}

{% step %}
#### Les attribuer

Renseignez le groupe de visibilité sur les **références** et sur les **utilisateurs** concernés.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
Un groupe attribué à un utilisateur ou à une référence ne peut pas être supprimé (poubelle en début de ligne) : rendez-le inactif.
{% endhint %}
