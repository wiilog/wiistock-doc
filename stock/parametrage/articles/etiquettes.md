# Étiquettes

**Chemin :** Paramétrage › Stock › Articles › Étiquettes

Le format de l'étiquette (taille, logo) se règle dans le paramétrage **Global**. Ici, vous choisissez ce qui s'affiche sur l'étiquette article :

| Option                                                                                                | Ce qui s'imprime                                                                                                                                                            |
| ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Afficher l'emplacement** de destination _ou_ de dropzone                                            | **Destination** : emplacement de la demande de livraison liée à l'article. **Dropzone** : dropzone de l'utilisateur qui a fait la demande de livraison depuis la réception. |
| **Afficher date de péremption**                                                                       | Date saisie lors du conditionnement.                                                                                                                                        |
| **Afficher la date d'entrée en stock**                                                                | Date d'entrée de l'article en stock.                                                                                                                                        |
| **Afficher le destinataire**                                                                          | Demandeur de la livraison faite depuis la réception.                                                                                                                        |
| **Afficher la quantité**                                                                              | Quantité contenue dans l'article.                                                                                                                                           |
| **Afficher le numéro de lot**                                                                         | Lot saisi lors du conditionnement.                                                                                                                                          |
| **Champ libre présent sur les étiquettes** + **Afficher le champ libre ci-dessus sur les étiquettes** | Un champ libre des articles, au choix.                                                                                                                                      |

<summary>Ordre des informations sur l'étiquette</summary>

1. QR code (ou code-barres)
2. Code-barres article
3. Destinataire / emplacement de destination (ou dropzone)
4. L/R : libellé de la référence
5. C/R : code référence
6. L/A : libellé de l'article
7. Numéro de lot
8. Date de péremption
9. Quantité
