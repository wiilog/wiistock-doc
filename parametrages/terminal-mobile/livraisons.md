# Livraisons

**Chemin :** Paramétrage › Terminal mobile › Livraisons

<figure><img src="../../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure>

**Autoriser la dépose des articles sur un emplacement libre** : à la validation de la livraison vous pouvez choisir un autre emplacement de Destination que celui qui a été choisi sur la demande.

**Autoriser la dépose des articles sur un emplacement libre** : à la validation de la livraison vous pouvez choisir un autre emplacement de Destination que celui qui a été choisi sur la demande.&#x20;

| Option                                                                         | Effet                                                                                                            |
| ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| **Autoriser la dépose des articles sur un emplacement libre**                  | À la validation, l'opérateur peut choisir une autre destination que celle de la demande.                         |
| **Afficher le code référence et le rendre scannable. Enlever le code article** | L'opérateur scanne le code de la référence (ex. : Gourde 2L) au lieu du code-barres article (ex. : ART23050001). |

Cliquez sur **Enregistrer**.
