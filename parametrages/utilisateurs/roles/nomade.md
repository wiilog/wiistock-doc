# Nomade

**Chemin :** Paramétrage › Utilisateurs › Rôles › rôle › **Nomade**

### Général

* **Connexion au nomade** **:** Ce paramètre actif permet au rôle associé d'utiliser l'application Nomade.
* **Activer les notifications :** Ce paramètre actif permet à l'application d'envoyer des notifications sur le terminal Mobile des utilisateurs disposant du rôle en cours de paramétrage.
* **Accès Track :** Ce paramètre actif permet au rôle associé de voir le menu "Track" sur un terminal Mobile.
* **Mode découverte** **:** <mark style="color:red;">**A utiliser uniquement en phase de tests .**</mark> Ce paramètre permet si il est activé que les utilisateurs qui disposent du rôle lié de manipuler des Articles/Références/UL sans vérifier la validité des codes à barres.
* **Connexion au nomade** : Se connecter à l'application nomade.
* **Activer les notifications** : Recevoir les notifications push sur le terminal.
* **Accès track** : Voir le menu Track sur le terminal.
* **Mode découverte** : **Uniquement en phase de test** : manipule articles, références et UL sans vérifier les codes-barres.
